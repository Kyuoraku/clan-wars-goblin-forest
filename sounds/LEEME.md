# Sonidos

Poné acá los sonidos originales extraídos de tu copia del SWF, renombrados así
(`.ogg`, `.mp3` o `.wav`). Los que falten se reemplazan con sonidos sintetizados.

| Archivo | Cuándo suena |
|---|---|
| `train` | encargás una unidad |
| `deny` | no alcanza el oro, la población o la cola está ocupada |
| `spawn_grunt` | sale un Bruto |
| `spawn_archer` | sale un Arquero |
| `hit_melee` | golpe cuerpo a cuerpo |
| `bow` | un arquero dispara |
| `arrow_hit` | impacto de flecha |
| `cannon` | dispara un cañón de base |
| `cannon_hit` | impacto de bala de cañón |
| `base_hit` | una base recibe daño |
| `death_player` | muere una unidad tuya |
| `death_enemy` | muere una unidad enemiga |
| `victory` | ganás |
| `defeat` | perdés |

Esta carpeta está en `.gitignore`: los audios del original tienen copyright y no se suben al repo.
